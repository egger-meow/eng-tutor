# Week 10 教師速讀｜Minecraft 第四個維度

## 本課定位

- 段考剛結束，正常推進，不再做整堂診斷考。以會考常見雙文本閱讀任務帶入一個新文法：**will + 原形動詞**。There will be 只做輕量延伸。
- 使用者已澄清：**沒有 200 字限制**。閱讀採新聞＋虛構實況對話，以完整情境、細節與推論作答，不以字數湊難度，也不聲稱為官方會考規格。
- 10 個核心字：player / company / simple / share / create / test / improve 七舊＋news / report / future 三新。三新字均為 master 的 1200 級、taught=no；舊字需先回想，不把曾列入教材當成已熟練。
- 依週次索引，先前已安排名詞、代名詞、進行式、can、頻率與 going to，第九週統整；本週從 master 的「八上－未來式」取 will 作小幅推進。這是家教進度，不宣稱翰林剛考完的單元就是未來式。master 仍未改 taught。

## 100–110 分鐘流程

| 時間 | 做法 |
| --- | --- |
| 0–10 分 | 問段考感受與最近看什麼實況；只記實際回覆。口頭檢查 Does he play? / Did he play? 各一句。 |
| 10–25 分 | 讀 A。學生圈遊戲名、年份；問「2027 是否等於今天就能玩？」不要先解釋全部單字。 |
| 25–40 分 | 分角色讀 B，找出 Leo 的誤會，以及哪句是在講自己的想法。專有名稱可中文帶過。 |
| 40–60 分 | 做八題閱讀；第 4、7 題要求指回原句。第 7 題不接受「遊戲通常元旦更新」等外部常識。 |
| 60–72 分 | 舊字先回想，教三新字；news 不可數、report 第二節較重（ri-PORT）、future 第一節較重（FU-ture）。不使用 IPA。 |
| 72–87 分 | 教 will / won't / Will ...? 與短答；把 does/did/will 後的原形並排。There will be 看懂＋一題即可。 |
| 87–103 分 | G1–G15，優先修正原形與問句位置；完成 20–30 秒自己的地圖介紹。 |
| 103–110 分 | 快速重問 Will you ...?；交代三次短作業，不加新字。 |

時間不足：先留 G9–G12 到下次口頭複習，不省略閱讀的依據回指與 will 問答。

## 容易卡住的地方

- **Minecraft 第四個維度確有官方消息。** 本課查核日 2026-10-14；2026-09-26 官方 recap 說 Sift 於 2027 年加入 Java／Bedrock。Dungeons II 與主遊戲分開處理；不把「另款遊戲已有」等同「Java 現在已有」。
- 官方本文只給 Java／Bedrock 的年份，沒有確切月日；只說「本來源未提供」，不推論所有官方管道都沒有日期。未來安排可能變動。
- B 的人物、影片標語、藍河、小屋、綠色動物與地圖製作順序均為**教學虛構**，不是已公布的 Sift 功能。不要補教來源沒有的怪物、進入方式或發售日期。
- will + 原形適用 he/she/it；學生若寫 will plays，先問「前面已經有哪個幫手？」再讓他自己修。
- be going to 與 will 有重疊，本週不要硬套「一個永遠有計畫、一個永遠沒計畫」；重點是句型與時間。
- There will be 不寫 There will is/are，也不把肯定句誤寫成 There will have。
- 閱讀題不是遊戲知識考；不熟專有名詞不扣分。第 8 題只由 May 想清楚標明自己的設計推論，不推斷其職業或實際遊玩經驗。

## sh 發音遷移（2–3 分鐘，可放單字段落尾端）

先以 share 示範連續氣流與不多加母音。**ship / shop / shed 三字在學生第一次試讀前不要示範**，只問「找得到同樣的 sh 嗎？」三字僅測起首 sh，不以整字母音的口音差異判定規則失敗。不教意思，不加入背誦或作業，不把老師帶讀後的成功當成獨立遷移。

記錄：第一次能否抓到 sh；是否多加「四／呃」；提示一次後是否改善。未知是否以前看過，標成「本課未示範」，不要聲稱一定生字。
