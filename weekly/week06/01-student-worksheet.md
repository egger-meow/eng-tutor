## Mission 4: Two Grammar Tools for Watching

### Tool 1: `be going to + 動詞` = 接下來會...

影片介紹規則、預告危險時一直使用這個句型。

- The zombies **are going to get** stronger.
- I **am going to build** a shelter.
- They **are going to come** for me.

完成預測：

1. The virus ____________________ spread.
2. The zombies ____________________ do more damage.
3. The last man ____________________ try to survive.

### Tool 2: 過去式 = 剛才發生了什麼

影片進入 Day 1 後，主角開始回顧自己的行動。

| 現在／原形 | 過去發生 |
| :--- | :--- |
| walk | walked |
| kill | killed |
| start | started |
| find | found |
| get | got |
| run | ran |
| make | made |

把 Day 2 行動排成合理順序，再改成過去式口頭說一次：

`run away → find seeds → plant the seeds → make bread → go fishing → get home`
