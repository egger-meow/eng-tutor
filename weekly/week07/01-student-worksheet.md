## Quest 4: Grammar Tools for a Team

### Tool A - Command: 動詞放句首

| Use | Pattern | Example |
| :--- | :--- | :--- |
| 要對方做 | **動詞原形** + ... | **Follow** the red signs. |
| 要對方別做 | **Don't + 動詞原形** + ... | **Don't touch** the box. |

命令句常省略 `you`。不要寫 `You follow...` 來當規則標題。

### Tool B - Let's: 提議大家一起做

> **Let's + 動詞原形.**

- **Let's read** the wall.
- **Let's choose** the left door.

`Let's` 包含說話的人，意思是「我們一起……吧」。

### Tool C - can / can't: 能不能、可不可以

> **主詞 + can / can't + 動詞原形**

- We **can ask** for one direction.
- We **can't go** back.

`can` 後面不要加 `to`，動詞也不要加 `-s` 或 `-ing`。

### Fast Choice

看到情境，選最自然的工具。

1. 牆上的正式規則，要大家停下：  
   A. Stop.　B. Let's stop.　C. We can stop.　D. Stopping.

2. 你提議全隊一起讀訊息：  
   A. Read the message.　B. Don't read the message.　C. Let's read the message.　D. We can't read the message.

3. 規則說玩家不可以碰箱子：  
   A. Players can touch the box.　B. Players can't touch the box.　C. Let's touch the box.　D. Touch the box.
