# Week 7 Teacher Guide: Escape Room Team

**Outcome:** 學生能整合邀請訊息、規則卡與隊伍對話，依文字證據做決定；能分辨 command、`Let's`、`can/can't` 的溝通功能。  
**CAP focus:** 主旨、細節、推論、文意猜字、跨文本整合、證據回指。  
**設計變化:** 本週以「決策」為主線，先讀任務、填 evidence organizer，再作答；不走長篇故事或影片時間卡。

---

## 字彙邊界

- 1200: `choose, enter, follow, rule`
- 800: `danger, direction, message, protect, secret`
- 正文與題幹不額外教中進階字。`goal, skill, light, wall, touch, wrong` 只當基礎功能字使用。
- 不自行加教 `clue, strategy, solve, escape route, penalty` 等字；需要時用中文一句帶過。

## 建議流程（100-120 分鐘）

### 1. Review + reading job（15-20 分）

- 快問 Week 6 的 `rule / prediction / event order`，只做口頭喚醒。
- 讀 Quest 1，讓學生知道本週不是逐句翻譯，而是找 goal / rules / best move。
- Quest 2 用「任務路徑」串字，不逐欄背中文。

### 2. First read: text type and purpose（15 分）

- 先遮住選擇題，只看 Text A-C。
- 問每份文字的用途：A 約時間與分工；B 定規則；C 現場做決定。
- 學生先獨立填 organizer；老師只追問「哪一句讓你這樣想？」

### 3. CAP questions + evidence（25-30 分）

- 1-4 獨立作答；5-8 要求先畫文字證據再選。
- 第 6 題是核心跨文本題：Text B 給 `blue = stop/read wall`，Text C 給 `red first` 與門的顏色。
- 若答錯，不先公布答案；請學生指出選項中哪一個字與原文衝突。

### 4. Grammar tools（20-25 分）

- 以溝通目的分類，不先背術語：
  - 規則叫一個人做／不做 → command
  - 提議我們一起做 → `Let's`
  - 說明能力或許可 → `can/can't`
- 三種後面都接動詞原形。用同一個 `read` 口頭轉換：`Read.` / `Don't read.` / `Let's read.` / `We can read.`
- 完成 Quest 4-5；修句時要求學生圈出多餘的 `to / -s / -ing`。

### 5. Transfer decision（15-20 分）

- Quest 6 先口頭分工，再寫四句。
- 不限制唯一答案，但四句功能必須不同，且不能違反 Green Room 規則。
- 可加一輪：老師扮演「故意做錯的人」，學生用 command 立刻阻止。

### 6. Exit check（5 分）

合上講義問：

1. Why should the team choose the left door?
2. Say one command and one `Let's` sentence.
3. What form comes after `can`?

## 題型設計紀錄

| Item | CAP operation | Main evidence |
| :---: | :--- | :--- |
| 1 | main idea / purpose | Text A as a whole |
| 2 | inference from roles | Text A skill lines |
| 3 | detail | Text B rule 4 |
| 4 | meaning from context | Text B rule 6 |
| 5 | rule-text comparison | Text B rule 3 + Text C |
| 6 | cross-text integration | Text B rule 4 + Text C wall line |
| 7 | inference / summary | all three texts |
| 8 | consequence | Text B rule 6 |

四選一是 transfer item 的共同外形，但不是唯一課堂活動；organizer、修句與新規則決策分別測證據整理、形式辨識與遷移。

## 常見卡點

- `follow a rule`：不是「跟在規則後面」，是「遵守規則」。
- `direction`：本篇兼有「方向／指示」語意，以規則 5 的求助指示為主。
- `secret`：從「選了就不能回去」和房間情境推得「不易知道或找到」，不要求背長定義。
- `Let's` 後不加 `to`。
- `can/can't` 後不加 `to`，也不因主詞是第三人稱而加 `-s`。
- `Don't` 後仍用原形，不用 `V-ing`。

## Homework

- A-B 做核心字 retrieval；B 形成完整決策流程。
- C 只測三種句型的共同原形規則。
- D 是新情境 CAP transfer；請學生一定抄一條支持答案的原文，不只交選項字母。
