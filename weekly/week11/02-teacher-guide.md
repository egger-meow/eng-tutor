# Week 11 教師速讀｜Who Took Number 67?

## 定位與邊界

- 主文法：want/decide/plan + to V；enjoy/keep/finish + V-ing；ask + 人 + (not) to V。對應八上「不定詞與動名詞」的部分內容，不涵蓋感官動詞。
- 先用 Q1-Q3 檢查上週因果與未來條件／時間子句；並用 G9-G12 對照 did/does + 原形、be + V-ing、keep + V-ing。不要因單字負荷低而把文法退回只教 will。
- 七個舊教材字 serious/control/notice/decision/popular/share/report；三新 repeat/explain（1200）、meaning（800）。舊教材出現不等於已熟練，尚未回報授課的字保留 taught=no。
- A 為 2025-12-10 UPI 報導改寫，依員工說法描述當時叫號，不聲稱今天每家門市都相同。B 全為虛構，不是 Jonathan 的真實經歷。不要把餐點變冷、叫兩次、65 號或對話當新聞事實。
- 本課可離線完成，不必播放來源歌曲或另找影片。67 的笑點不要求唯一中文意思；可以讓學生說他自己的用法。

## 120 分鐘流程

| 時間 | 做法 |
| --- | --- |
| 0-20 分 | Q1-Q3 複習；用中文問「66 後面如果直接 68，怎麼回事？」舊字先回想。 |
| 20-40 分 | 讀 A，再分角色讀 B 四幕。B2 結束先猜後續；不先講反轉。 |
| 40-55 分 | R1-R8、E1-E3，請學生指出支持答案的句子。R5 不按字面翻譯成吃七份餐。 |
| 55-65 分 | 三個新字、W1-W4、三個片語。ng 遷移約 2 分鐘，先試再示範。 |
| 65-80 分 | 用 want to eat / enjoy eating / ask Kevin not to laugh 三組板書；時間標記在第一個動詞。 |
| 80-105 分 | G1-G22；修句要說明前面的哪個字決定後面形式，合併題注意 me 的指涉。 |
| 105-115 分 | 熟練再做 X1-X2；Speak 換成學生自己的梗。較慢則先完成 G17-G22，省略加分題。 |
| 115-120 分 | 交代 Homework，請學生不看表說出三種接法各一句。 |

若只有 110 分鐘，舊字複習縮至 15 分鐘、略過 X1-X2；保留新情境應用與口說。

## 卡點與精準說法

- 不是「所有兩個動詞連用都加 to」，也不是「喜歡都接 ing」；本週先掌握這六個常用動詞的搭配。like/start 的多種接法不在本週考點，不拿來出單一答案題。
- decides/decided 決定主句時態，後面仍 to wait；enjoys/enjoyed 後均接 watching。decision 是名詞，decide 是動詞，簡短連結即可。
- Does he **want to eat**?：does 管 want，want 管 to eat。He **keeps laughing** 不需 is；He **is laughing** 才是現在進行式。
- ask Kevin **not to laugh** = 要 Kevin 不要笑；**didn't ask** Kevin to laugh = 沒有提出笑的要求，兩者不等義。
- G18 的 me 是 Kevin，轉述可寫 Kevin asked Jonathan to wait for **him**；G19 不加 said，不把 Kevin 省略。
- stop laughing 是原本在笑、後來不笑；stop to eat 是停下原本活動去吃。只作進度足夠時的延伸，不以兩題表現推論全面掌握動名詞。
- 新詞意思先由文境猜，再看表；不另塞 viral、trend、customer、employee 等中階字。

## ng 遷移

用 meaning/waiting 示範字尾 ng 鼻音連續收尾，不補 g 的爆破或母音。wing/sang/hung 三字第一次試讀前不要念；只測字尾 ng，不教字義，不考母音口音，不放入 Homework。可能以前見過，只稱「本課未示範」，不要宣稱完全陌生。記錄首次與提示後表現分開。
